## 설치
- **Claude Code**: zip을 풀어 폴더째 `~/.claude/skills/` 에 넣으면 끝.
- **Claude 앱(claude.ai)**: 설정 → 기능(Capabilities) → 스킬 → zip 업로드.

설치 후 "우리 회사 AI 봇 정리해줘", "챗봇 효과 A/B 테스트 설계해줘"처럼 말하면 스킬이 실행돼요.

뉴스레터 구독: https://starofai-newsletter.vercel.app
