# AI 임팩트 실험 설계

월마트는 "스파키를 쓰는 고객은 주문금액이 35~40% 높다"고 발표했지만, 원래 큰 장을 보는 고객이 스파키를 켰을 수도 있다는 비판(Laura Klein)을 받았다. **사용자 vs 비사용자 비교는 효과를 부풀린다.** 이 스킬은 경영진에게 "AI 덕분"이라고 말할 수 있는 실험을 설계한다.

## 1. 입력 받기
- AI 기능 한 줄 설명, 대상 사용자(고객/직원), 현재 하루 사용자 수
- 증명하고 싶은 효과 (매출, 주문금액, 처리 시간, 전환율 …)와 현재 평균값
- 기존에 본 숫자가 있다면 어떻게 계산했는지

## 2. 편향 점검 (먼저 말해줄 것)
기존 숫자에 아래가 있으면 표시하고 이유를 한 줄로 설명한다.
- **자기선택**: 스스로 기능을 켠 사람만 비교했나?
- **헤비유저 효과**: 앱을 자주 쓰는 사람이 새 기능도 먼저 발견하나?
- **시기 효과**: 도입 전후 비교에 시즌·프로모션이 섞였나?
- **생존 편향**: 중간에 이탈한 사용자를 뺐나?

## 3. 실험 설계
- **랜덤 단위**: 사용자 / 매장 / 팀 중 하나. 서로 영향을 주면 더 큰 단위로.
- **그룹**: A(기능 노출) vs B(미노출). 노출이 곧 사용은 아니므로 **노출 기준(ITT)**으로 비교한다.
- **핵심 지표 1개**: 결정에 쓸 단 하나의 숫자.
- **가드레일 지표 2~3개**: 반품률, 재구매율, 상담 이관률, 처리 오류율 등 나빠지면 안 되는 것.
- **표본 크기**: `scripts/sample_size.py`로 계산한다.
  ```bash
  python3 scripts/sample_size.py --baseline 52000 --sd 30000 --lift 0.05
  # 비율 지표면: --rate 0.12 --lift 0.10
  ```
  하루 사용자 수로 나눠 **필요 기간**을 알려준다. 2주 미만이면 최소 2주(요일 효과)로 맞춘다.
- **중단 규칙**: 가드레일이 기준보다 나빠지면 즉시 중단.

## 4. 보고 양식 (실험 후)
| 지표 | A | B | 차이 | 95% 신뢰구간 | 판정 |
|---|---|---|---|---|---|
한 줄 결론은 "노출 그룹의 ○○이 △% 높았고, 가드레일은 유지/악화"로 쓴다. 신뢰구간이 0을 포함하면 "효과 확인 안 됨"이라고 쓴다.

## 5. 출력
실험 설계서 1개: `편향 점검 → 가설 → 그룹·단위 → 지표 → 표본·기간 → 중단 규칙 → 보고 양식`. 1쪽.
