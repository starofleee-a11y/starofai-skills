# AI 챔피언 프로그램 설계

라이선스를 뿌린다고 사람들이 쓰지는 않는다. SC제일은행은 기술·보안·현업 사이를 잇는 사용자 '챔피언' 50명을 주요 부서에서 뽑아 온·오프라인 교육을 했다. 그룹 전체 기준 월간 사용률은 91%였다(2026년 9월 발표). 이 스킬은 같은 구조를 우리 조직 크기에 맞춘다.

## 1. 입력 받기
- 부서 목록과 부서별 인원(표나 붙여넣기)
- 도입한 AI 도구와 라이선스 수
- 지금 사용 데이터가 있으면 부서별 월간 활성 사용자 수
- 교육에 쓸 수 있는 시간(예: 주 1시간, 4주)

## 2. 챔피언 인원과 배분
- 기본 비율: 직원 50~100명당 1명, 부서마다 최소 1명. 인원 계산 표를 만든다.
- 사용률이 낮은 부서에 1명씩 더 배정한다.
- 선발 기준 4가지: 현업 업무를 잘 앎, 동료가 질문하러 오는 사람, 보안 규칙을 지킬 사람, 주 1시간을 낼 수 있음. 개발 실력은 기준이 아니다.

## 3. 4주 커리큘럼
주차별로 "배우는 것 / 직접 해 볼 과제 / 부서에 퍼뜨릴 것"을 표로 만든다. 기본 흐름:
1주 회의 요약과 메일 초안(가장 많이 쓰이는 기능부터. SC 그룹에서는 회의 요약이 일반 기능보다 5배 많이 쓰였다) → 2주 문서·보고서 초안 → 3주 부서 고유 업무 프롬프트 3개 만들기 → 4주 금지 데이터와 결과 검토 책임, 사례 공유회.

## 4. 측정 지표
월 1회 보는 지표 5개를 정의하고 계산식과 데이터 출처를 적는다.
| 지표 | 계산 | 출처 |
|---|---|---|
| 월간 사용률 | 한 달에 1번 이상 쓴 사람 / 라이선스 수 | 관리자 사용 리포트 |
| 1인당 월 프롬프트 수 | 총 프롬프트 / 활성 사용자 | 관리자 리포트 |
| 기능별 사용 건수 | 회의 요약, 메일, 문서 등 | 관리자 리포트 |
| 주간 절감 시간(자가 보고) | 설문 중앙값 | 아래 설문 |
| 부서 고유 활용 사례 수 | 챔피언 공유회 발표 수 | 챔피언 보고 |
절감 시간은 자가 보고라 부풀려질 수 있다고 보고서에 반드시 적는다. 가능하면 같은 업무의 전후 소요 시간을 2~3건 직접 재서 함께 낸다.

## 5. 월간 설문(5문항)
이번 주 AI로 아낀 시간, 가장 많이 쓴 기능, 쓰다가 막힌 점, AI 결과를 고친 비율, 동료에게 추천할지. 객관식 4문항 + 주관식 1문항.

## 6. 출력
마크다운 문서 1개: `챔피언 배분 표 → 선발 기준 → 4주 커리큘럼 표 → 지표 정의 표 → 설문 → 첫 달 일정 → 다음 행동 3개`. 1~2쪽.
