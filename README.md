# StarofAI Skills

StarofAI 뉴스레터 「AI 실제로 어떻게 활용해?」(매주 목요일)에서 소개한 AX 사례를 **내 업무에 바로 적용**할 수 있게 만든 Claude 스킬 모음이에요. 무료로 받아 쓰세요.

| 호 | 사례 | 스킬 | 다운로드 |
|---|---|---|---|
| No.01 | 월마트 슈퍼 에이전트 | `ax-super-agent-map` — 흩어진 AI 봇을 입구 3~4개로 묶는 설계서 | [zip](https://github.com/starofleee-a11y/starofai-skills/releases/download/biz-001/ax-super-agent-map.zip) |
| No.01 | 월마트 스파키 성과 논쟁 | `ai-impact-experiment` — AI 효과를 인과로 증명하는 A/B 실험 설계 | [zip](https://github.com/starofleee-a11y/starofai-skills/releases/download/biz-001/ai-impact-experiment.zip) |

## 설치
- **Claude Code**: zip을 풀어 폴더째 `~/.claude/skills/` 에 넣으면 끝.
- **Claude 앱(claude.ai)**: 설정 → 기능(Capabilities) → 스킬 → zip 업로드.

설치 후 "우리 회사 AI 봇 정리해줘", "챗봇 효과 A/B 테스트 설계해줘"처럼 말하면 스킬이 실행돼요.

뉴스레터 구독: https://starofai-newsletter.vercel.app
